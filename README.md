# ระบบเช็คอินพนักงานนอกสถานที่

บันทึกการเข้า-ออกงานของพนักงานที่ออกไปทำงานที่ไซต์งานนอกออฟฟิศหรือไปพบลูกค้า
โดย **เช็คอินได้เฉพาะเมื่ออยู่ในพื้นที่นั้นจริง** และ **ต้องแนบรูปถ่ายหน้างาน**
ข้อมูลทั้งหมดเก็บลง Google Sheet

> โปรเจกต์นี้แยกอิสระจากระบบอื่น — ใช้ Google Sheet ของตัวเอง
> ไม่เกี่ยวข้องและไม่แตะข้อมูลของแอพที่มีอยู่เดิม

## โครงสร้าง

```
Checkin-App/
├── Checkin-API/     Google Apps Script — ทำหน้าที่เป็น API คุยกับ Sheet + Drive
└── docs/            หน้าเว็บ — โฮสต์บน GitHub Pages
```

| โฟลเดอร์ | รายละเอียด |
|---|---|
| [`Checkin-API/`](Checkin-API/README.md) | วิธีติดตั้งฝั่ง Apps Script + โครงสร้างชีต |
| [`docs/`](docs/README.md) | วิธีเปิด GitHub Pages + แก้ปัญหาที่พบบ่อย |

## หน้าเว็บทั้ง 3

| หน้า | ใครใช้ | ทำอะไรได้ |
|---|---|---|
| `index.html` | พนักงาน | ใส่รหัส → เลือกหน่วยงาน (เรียงจากใกล้สุด) → ถ่ายรูป → เช็คอิน/เช็คเอาท์ |
| `dashboard.html` | หัวหน้างาน | สรุปตัวเลข, แผนที่จุดเช็คอิน, ตารางย้อนหลัง, ดูรูป, ส่งออก CSV |
| `admin.html` | ผู้ดูแล | ปักหมุดหน่วยงานจากแผนที่ + ตั้งรัศมีรายจุด, จัดการรายชื่อพนักงาน |

## ทำไมหน้าเว็บถึงไม่ได้อยู่ใน Apps Script

Apps Script Web App ครอบหน้าเว็บไว้ใน `<iframe>` ของ Google ซึ่งบล็อกการขอตำแหน่ง GPS
ในหลายเบราว์เซอร์ — เป็นสาเหตุที่แอพเช็คอินมักขึ้น error "ระบุตำแหน่งไม่ได้"
ทั้งที่พนักงานยืนอยู่หน้างานจริง

แยกหน้าเว็บออกมาโฮสต์เองแล้ว GPS ทำงานเหมือนเว็บปกติทุกประการ

```
มือถือพนักงาน → GitHub Pages (หน้าเว็บ + GPS) → Apps Script (API) → Google Sheet + Drive
```

## กติกาที่ระบบบังคับ

| เงื่อนไข | เช็คอิน | เช็คเอาท์ |
|---|---|---|
| ต้องอยู่ในรัศมีหน่วยงาน | ✅ บังคับ (บล็อกถ้าอยู่นอกพื้นที่) | ❌ ไม่บังคับ แต่บันทึกพิกัดไว้ |
| ต้องแนบรูปถ่าย | ✅ บังคับ | ❌ ไม่บังคับ |

การตรวจพื้นที่ทำทั้งฝั่งหน้าเว็บและฝั่งเซิร์ฟเวอร์ — ต่อให้แก้โค้ดในเบราว์เซอร์เพื่อข้ามการตรวจ
ฝั่งเซิร์ฟเวอร์ก็คำนวณระยะห่างใหม่แล้วปฏิเสธอยู่ดี
